# Fonts

| Use | Font | Files | Licence |
| --- | --- | --- | --- |
| Logo / huge title | **Orbitron** | `orbitron/` (included) | SIL Open Font License, see `orbitron/OFL.txt` |
| Normal titles | **Octarine** by Alexander Slobzheninov | `octarine/` (Light, Bold + obliques) | Light & Bold are free for personal and commercial use (check the readme that comes with the download) |
| Floating keywords | **Organo** by Nikola Nikolov | `organo/Organo.woff2` (letters, digits, space only) | Free (Creative Commons Attribution, credit the designer) |

All three are converted to `.woff2` for the web. Organo has no punctuation, so characters like `-` in a keyword
show in the fallback font.
